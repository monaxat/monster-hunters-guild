# The Wyrm Hunters — Website

## Project Overview

The Wyrm Hunters is a monster-hunting guild seeking to establish a professional presence on the internet, attract new clients, and gradually expand its online presence over time.

The project description and website requirements have already been prepared. The next step is to design and implement the website frontend based on the supplied documentation and assets.

Some preliminary work has already been completed, including the project concept, website content, visual identity, technical direction, and visual asset preparation specifications.

## Project Documentation

- `description.md` — Website brief, project goals, page structure, content, and functional requirements.
- `visual-identity.md` — Visual direction, color palette, typography guidance, and general design principles.
- `technologies.md` — Recommended technologies, technical requirements, architecture considerations, and implementation guidelines.
- `logo.md` — Guild logo and favicon design specifications.
- `hunters.md` — Character descriptions and visual specifications for the guild's hunters.
- `clients.md` — Client portrait descriptions and visual specifications for testimonial sections.
- `asset-preparation-specification.md` — Instructions for inspecting, preparing, optimizing, and organizing the source visual assets.

## Raw Assets

The `raw-assets/` directory contains the original visual materials provided for the website, grouped into subdirectories such as:

- `logo/` — Source guild logo artwork.
- `favicon/` — Source favicon artwork.
- `hunters/` — Hunter character portraits.
- `clients/` — Client portrait artwork for testimonials.
- `icons/` — Source image containing the guild service icons.

These are source files for the asset-preparation stage. Review them and follow `asset-preparation-specification.md` before using or modifying them. Preserve the original files; place prepared and optimized assets in a separate output directory.

## Next Step

Review the documentation and available assets, then plan and implement the responsive website frontend. Follow the established visual identity and technical guidelines, and ask for clarification when requirements are ambiguous.
